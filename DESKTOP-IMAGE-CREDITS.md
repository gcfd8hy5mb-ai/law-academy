# Law Academy desktop photograph sources

The desktop mockup-inspired photo backgrounds are drawn from Wikimedia Commons. They are externally served as CSS background images; if they fail to load, the navy/gold design remains usable. Do not remove attribution.

- **U.S. Supreme Court exterior**: “Exterior of Supreme Court Building 20240601.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Exterior_of_Supreme_Court_Building_20240601.jpg . Check file page for photographer and license before redistribution.
- **Gavel**: Santeri Viinamäki, “Gavel 2016-05-25.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Gavel_2016-05-25.jpg . Creative Commons attribution/share-alike conditions are described on the file page.
- **Scales**: St. Louis Circuit Attorney's Office, “Justice scale and flag.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Justice_scale_and_flag.jpg . See file page for attribution and license.
- **Law books**: Ndawoje, “Ghalib Chamber Law Library.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Ghalib_Chamber_Law_Library.jpg . CC BY-SA 4.0.
- **Wooden gavel**: Santeri Viinamäki, “Wooden gavel 20170417.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Wooden_gavel_20170417.jpg . Refer to file page for licensing.
- **Law book shelves**: Ndawoje, “Law Book shelf at the Ghalib Chamber Library.jpg”, Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Law_Book_shelf_at_the_Ghalib_Chamber_Library.jpg . Refer to file page for licensing.

These photos are not the original AI-rendered illustration used in the approved visual reference, but serve as licensed real-world imagery in the working desktop build. License obligations must be checked before reuse outside the app.
